# 让黑塔制作插件

工坊把生成、检查、试跑、审阅与安装分成可检查的步骤。模型必须通过当前连接的文本验证；正式安装仍由用户确认。不同下载批次的功能以Release说明为准。

## 生成第一份候选

打开 **设置 → 插件 → 执行插件 → 让黑塔制作**。

1. 选择制作模型。列表仅显示当前配置下已通过文本验证的模型，默认选黑塔的persona模型；支持时可调整思考强度。这不会修改聊天或工作台的日常模型绑定。
2. 在“制作要求”写清输入、希望得到的结果和允许做的事，例如：“把输入文字拆成检查清单，在只读面板里展示，不访问项目或网络。”
3. 点击“生成候选”。生成只接收本次要求及明确打开用于修订的旧候选，不附加聊天历史、记忆、项目文件或凭据，也不调用工具或联网搜索。

完整返回的内容通过严格插件格式检查后，保存为独立制作草稿。生成不会安装或运行插件。可以“停止本次处理”；取消、模型配置变化、超时或非法输出不会自动采用迟到结果。试跑结果先返回但进程仍在退出时会显示“正在收尾”，等释放完成后才允许下一项操作。

缺少可用模型时先到“连接与模型”配置并验证。已保存候选的原模型不可用，不会妨碍离线检查、手动编辑保存、试跑或安装；重新生成仍需要当前已验证模型。

## 草稿与手动修改

展开“制作草稿”可打开已保存候选。展开“候选 JSON · 可手动编辑或粘贴”查看或修改完整插件包，然后点击“检查并保存草稿”。格式错误会保留编辑文本并提示修正，不静默清空或自动安装。

修改需求、模型或源码后，旧试跑展示和安装预览失效；先保存，再检查新版本。源码有未保存修改时，重新生成按钮会要求先保存或放弃，避免忽略手动修改。切换草稿前同样先保存或明确放弃当前编辑。未保存内容只在当前面板中，不能当作已落盘备份；关闭时按提示决定是否放弃。

保存的候选位于独立稿库，和已安装插件分开。制作草稿与其他插件资料共同计入512MiB逻辑大小预算；最多16份草稿、单记录3MiB，完整插件包仍受2MiB格式上限约束。损坏记录保留并列为无法读取，不当作空稿覆盖。

## 逐个动作试跑

选择“试跑操作”，填写该动作的参数；同时支持聊天和工作台的动作还可选择模拟区域。点击“隔离试跑所选操作”。

试跑执行实际插件JavaScript，但所有宿主能力都接**内存样本**：不会读取真实项目、执行本机命令、请求公网、加入日常聊天草稿或安装插件。结果中的视图只读，按钮不能继续执行真实操作。模拟文件、提案及草稿只显示在结果中，不进入用户文件库。

一项操作试跑完成，只覆盖该动作、本次参数和样本；不能推断其他动作或真实环境也成功。缺少命令/联网等外部样本时会标记“外部能力未验证”，不会编造成功结果。试跑结果和过程记录都保留这种区别。

普通文字处理通常不需要额外样本。需要模拟项目、私有资料、网络或命令时，在“试跑样本 JSON（可选）”填写需要的部分；下面示例全部是假数据，不会执行其中的命令或访问网址：

```json
{
  "workspace": [{ "path": "sample.txt", "text": "第一行\n第二行\n" }],
  "privateValues": { "count": 1 },
  "network": [{
    "url": "https://example.com/",
    "method": "GET",
    "response": { "status": 200, "contentType": "text/plain", "body": "模拟页面" }
  }],
  "commands": [{
    "argv": ["node", "--version"],
    "result": { "exitCode": 0, "stdout": "v24.0.0\n", "stderr": "" }
  }]
}
```

样本要与插件实际请求的路径、网址/方法/请求体、命令参数及工作目录匹配。提供样本不会补授插件未声明的能力；越权仍会被拒绝。样本JSON最多512KiB，累计保留结果数据有1MiB上限。

## 审阅差异和权限，再确认安装

点击“查看差异与安装权限”。此前的制作设置和试跑结果会折叠，保留内容；需要修改时展开即可，修改会立即撤掉旧安装预览。

安装区显示：

- 当前已安装版本与候选的实际差异。清单包含权限和动作变化，源码包含新增、修改、删除；停用插件也作为旧版本对照。
- “仅看变更”“修改前全文”“修改后全文”，红绿行底色、语法高亮及分页。新装则展示将加入的内容。
- 每个动作的试跑情况，包括尚未试跑、模拟完成、失败或外部未验证。允许跳过试跑后明确安装，但这些状态不会被改写成真实环境通过。
- “允许的操作”。所有权限初始不勾选，联网权限同时列出来源和方法。

选好允许的操作后，点击“确认安装此候选”或“确认更新此候选”。不勾选也可安装，但需要未授权能力的动作不能运行。安装前会再次核对候选版本、内容与旧安装基线；发生变化时应重新预览，不能凭旧差异确认。生成候选不能通过普通导入确认绕过这条绑定。

**安装不会自动运行。** 安装成功后，在工作台或聊天的“快捷操作 → 执行插件”选择操作，填写参数后明确运行；结果需要加入草稿时仍另点确认，不自动发送。实际运行遵守当前权限：工作区提案需用户明确申请应用；插件命令包括完全访问档位也逐条确认。本机命令按当前用户权限运行，不等于OS文件/网络隔离。

设置里的原插件列表继续提供启用/停用、调整权限、更新和历史版本回退。回退先展示实际差异并重新确认授权；详细执行能力见[SDK](PLUGIN_SDK_V2.md)、[命令边界](PLUGIN_COMMANDS_V1.md)和[文件说明](PLUGIN_FILES_V1.md)。

## 删除普通或损坏草稿

在“制作草稿”选择对应删除入口，先查看名称、文件数、逻辑大小和影响范围，再点“确认删除制作草稿”。对于有可核验ID的损坏稿，入口为“检查删除损坏草稿”。

删除范围只包含这份制作草稿，不移除已经安装的插件，不删除聊天、项目或生成文件。无法完整确认范围/大小时显示“无法统计”并禁用确认；无法辨认的未知资料继续保留。预览过期或资料变化要重新检查，不能扩大删除范围。

删除不可撤销，也不是多文件原子事务。中途取消或失败可能部分完成，界面会列已删文件/字节和剩余数量，不自动重试。安装后删制作草稿不影响已安装插件，但会失去继续编辑这份草稿的内容；需要保留时不要确认删除。

## 遇到失败

生成或检查失败会保留当前需求和编辑；保存、安装或删除结果无法确定时，应重新打开/刷新对应列表核对，而不是连续重复确认。无法读取的记录不静默清空。源码回退也不能恢复已经明确删除的文件。

## 验证范围

已在一个DeepSeek Flash服务上生成小型插件，未手修模型源码，经严格解析、本地实际QuickJS试跑、明确测试安装和安装后运行取得正确结果。这个有限样本不保证所有模型输出都正确；实际项目、网络、命令和原生操作仍应逐项检查。

远程市场、任意界面脚本注入、无人确认安装或修改应用核心不属于该流程。试跑数据与正式运行始终分开。
