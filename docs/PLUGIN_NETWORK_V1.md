# 插件受限联网

network.request 提供受限HTTPS公网文本请求。模型联网搜索、插件联网和获准本机命令自行联网是三条不同路径，不能互相替代授权。

插件只能提交url、method和可选body；代理与解析策略由用户在宿主设置中明确选择。

## 授权与使用

执行插件可以声明 `network.request`，列出允许访问的 HTTPS 来源和请求方法。安装预览展示这些范围，由用户明确勾选；动作还必须声明该能力。来源包含协议、主机和有效端口，不是整互联网权限，也不是文件读取权限。

| 使用位置 | 实际授权方式 |
| --- | --- |
| 与黑塔聊天 | 已安装并授予来源/方法后，用户明确运行动作即可联网；不隐式读取工作区，不调用模型 |
| 工作台：只读或计划模式 | 拒绝所有插件联网，包括 GET/HEAD |
| 工作台：工作区编辑 | 每次请求进入当前Session的权限确认，展示完整地址、方法及正文UTF-8字节数；拒绝或超时不发送 |
| 工作台：完全访问 | 沿用既有档位覆盖策略；仍检查插件授权、来源/方法、当前会话和公网地址边界 |

工作台使用既有独占工作区操作门，不创建模型轮次；确认前后均复核当前身份、权限修订和取消状态。安装授权不能绕过只读/计划锁。预览或运行插件不自动附加附件、准备草稿或发送聊天消息。

插件联网与输入框中的模型“联网搜索”是不同能力：后者控制服务商搜索，前者由插件安装授权及本节策略决定。关闭模型搜索不会撤回已经授予插件的联网能力；可在插件设置调整授权、停用插件或停止当前运行。

## 插件联网设置（）

本节功能尚未进入冻结候选，本机安装也未更新。在“设置 → 插件 → 插件联网”展开设置，默认是“直连 · 系统解析”。查看或编辑不会探测端点，只有点击“保存插件联网设置”才修改宿主配置；取消会恢复当前已保存值。

1. 需要代理时选择“指定 HTTP(S) CONNECT 代理”，填写实际代理的数字IP和端口。`http://127.0.0.1:7890`仅示意格式，不是自动采用的地址。允许IPv4或带方括号的IPv6；不接受域名代理、账号密码、查询参数、fragment或根路径之外的路径。
2. 系统解析若返回假IP或保留地址，仍会拒绝。需要时明确选择“自定义 HTTPS 解析（DoH）”，填写可信解析服务的HTTPS端点及其一个实际公网引导IP。端点不接受凭据、query或fragment；这些字段是连接端点，不是Key输入框。
3. DoH会把所请求的域名与A/AAAA查询类型发送给所选解析服务，不发送原URL的路径、query或请求正文。引导IP用于直接建立到解析服务的连接，证书仍按解析服务的原主机名校验；地址不可用时不会暗中改用其他DNS。
4. 点击保存。配置版本变化会停止在途插件请求；输入冲突或保存失败会保留编辑，需明确重新读取再处理，不会自动重试。界面显示“配置待处理”时，展示的默认值不代表已经启用直连。

代理只收到宿主已验证的公网数字目标IP，目标HTTPS证书仍按原目标主机名校验。HTTPS代理自身也要通过证书校验：因为代理地址必须是数字IP，其证书必须覆盖该IP的SAN；不会为了可连接而忽略证书错误。代理的最终物理路由仍由用户选定的可信代理负责，客户端不能独立证明它最终连接的位置。

当前不支持PAC、SOCKS、代理认证、带Key的DoH端点、环境变量/系统代理自动继承或失败后的自动直连/其他解析回退。设置只供插件受限联网使用，不修改系统代理、DNS或模型Provider通道；也不改变每条`commands.run`（包括完全访问档位）都须确认的规则。已批准的本机程序仍可自行访问网络，不由这套SDK来源规则代管。

### 配置保存与损坏处理

联网设置是独立宿主小配置，不含Provider Key、聊天或Guest私有资料；记录最多16KiB。缺省首次使用为直连/系统解析；损坏或无法安全核验的记录暂停联网，不把显示默认值当成可用策略。

用户明确保存有效配置时，可安全完整读取的损坏原字节先归档，再提交新记录；损坏原件最多8个归档名额，同一SHA的坏件复用，未知条目或残留临时文件也占名额。达到上限时拒绝继续覆盖，不自动删除原件。无法核验的链接、过大记录或变化中的文件不会被静默清空。此小配置有独立上限，不把它写成五类插件资料512MiB预算的一部分。

首次发布后临时文件清理失败，只有精确宿主临时文件名、同目录身份和全部硬链接数量均核对一致，才继续读取已提交配置；外部硬链接仍拒绝。残留会保留，归档目录中的残留占后续名额，不以静默删除解决。

本进程曾观察到配置文件存在，之后文件消失时会暂停联网，直到用户明确保存。跨重启若文件已不存在，目前没有额外历史标记，仍按首次缺省处理；不声称能够识别所有历史丢失。读取、保留原件和提交是Node条件操作，不承诺OS多文件事务或断电原子性。

## SDK

```js
const response = await api.network.request({
  url: 'https://example.com/',
  method: 'GET'
});
return { status: response.status, ok: response.ok, body: response.body };
```

参数只有 `{ url, method, body? }`。url最多2048个UTF-16单位，只接受HTTPS，拒绝用户名、密码、fragment（包括空#）、非法字符及端口0，显式端口必须为1–65535。method仅允许 `GET`、`HEAD`、`POST`、`PUT`、`PATCH`、`DELETE`、`OPTIONS`，必须在安装授权的方法范围内。GET/HEAD不允许正文；其余方法的body是可选字符串，不是对象或二进制，也不能传自定义header。

返回 `{ status, ok, contentType, body }`：ok仅表示HTTP状态为2xx，不能代替业务成功判断；合法的4xx/5xx文本响应可供插件检查。contentType是规范化MIME，body是严格UTF-8文本，JSON或XML不自动解析。HEAD/204/205返回空正文。重定向被拒绝，不自动跟随或重试；失败不伪装成空页面。

body按 `text/plain; charset=utf-8` 发送，宿主自行设置Content-Length；插件不能填写Authorization、Cookie、Host或其他header。权限确认只展示地址、方法和正文大小，不展示正文，也不读取服务商Key。完整URL包含query，因此插件作者应避免把秘密写入地址、参数、日志或结果视图。

## 连接与资源边界

- 使用独立Node HTTPS和私有Agent，不共享Electron浏览器session、Cookie、HTTP认证或Provider Key，不读取个人代理环境。TLS沿Node运行时受信根校验，不提供忽略证书或Guest自定义CA的入口。
- 系统解析与明确选择的DoH都先取得A/AAAA结果；全部目标答案须通过保守的公网单播检查，再固定选定IP。混合公网/私网、回环、链路本地、特殊用途地址及不允许的本地域名仍拒绝。代理入口是用户明确配置的例外，不能成为插件目标或DoH引导地址的私网例外。
- DoH采用RFC8484 `application/dns-message`，有界核对问题、CNAME链和压缩指针；截断、循环、不匹配、扩展错误码或不支持的EDNS版本失败。最多16个目标地址、64条DNS记录，DNS消息最多65,535字节，不自动重试或改用远端代理解析目标域名。
- Guest不能请求CONNECT、WebSocket或协议升级。宿主只为明确代理建立数字IP CONNECT隧道；不跟随目标或DoH重定向，不接受压缩响应、自定义header或非文本下载。目标文本仅接受UTF-8/ASCII的 `text/*`、JSON、XML及相应 `+json`/`+xml` MIME。
- 请求body最多48,000个UTF-16单位且UTF-8最多64KiB；能力参数另受64KiB JSON预算。目标响应正文最多64KiB、header最多8KiB，返回JSON另受256KiB预算；DoH和CONNECT头同样有界。
- 每服务最多4个在途请求。单次网络15秒共同覆盖DNS/DoH、代理连接、目标TLS与响应；broker的60秒总等待仍包含权限确认。配置版本或规范化内容变化，会停止旧出口请求。
- 会话、授权、插件状态变化、停止或关闭也中止请求并丢弃迟到结果。取消不能撤销已发送的远端操作；超时不能证明服务端未收到，不自动重发POST。

实现入口：[网络服务](../packages/gui/src/main/plugins/plugin-network-service.ts)、[显式出口与DoH](../packages/gui/src/main/plugins/plugin-network-egress.ts)、[联网设置存储](../packages/gui/src/main/plugins/plugin-network-settings-store.ts)、[能力代理](../packages/gui/src/main/plugins/capability-broker.ts)、[运行控制器](../packages/gui/src/main/plugins/executable-plugin-controller.ts)。Guest只取得有界数据，不取得socket、fetch、代理配置或Node对象。

## 公开页面示例

[public-page.herta-plugin.json](examples/plugins/public-page.herta-plugin.json)只声明 `https://example.com` 的GET和 `ui.present`。安装时查看代码并勾选这两项；运行“读取公开页面”，path默认为`/`、最多512单位，不接受其他主机或fragment。

结果显示HTTP状态、类型和前6000个Unicode字符，正文使用纯文本代码块，HTML不会执行；不支持的控制字符替换为�。不写草稿、不生成文件、不调用模型。示例不调用模型。此前离线样例检查只证明数据通路；另有生产网络服务通过显式代理、可信DoH和原主机TLS获取公开页面的真实正向检查，二者不能混为同一次端到端运行。

## 验证与兼容范围

已使用明确配置的HTTP CONNECT代理和可信DoH，完成A/AAAA解析、固定公网IP连接、原域名TLS验证及公开页面HTTP200返回。没有通过放行保留地址、关闭证书校验或自动切换出口取得成功。

这只覆盖已验证的端点和请求，不保证所有代理、证书或网络环境兼容；保存配置不等于连接测试。失败保留固定诊断，不自动重发有副作用的请求。尚不支持代理认证、SOCKS或PAC；需要这些功能时不能以放宽现有约束代替实现。
