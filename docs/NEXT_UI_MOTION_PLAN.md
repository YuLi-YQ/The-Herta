# 下一阶段候选方案 · 轻量界面动效

日期：2026-10-16（America/Denver）。状态：用户已选择轻量界面动效，R33实施及有限验收完成；候选已打包，尚未发布/安装。详见reports/round-33.md。以下保留原设计边界。

## 核心目标

保持The Herta为实用的Windows桌面编程助手，工作台与角色聊天分开；深紫/金色和大黑塔视觉服务于工具使用。动效不延迟操作，不改变权限、执行和错误语义，不干扰输入、代码阅读及历史滚动。继续保留白/灰白浅色与经典界面回退。

## 现有基础

R22已接入Lucian #039模式标签，含0.5秒胶囊移动与系统减少动态效果支持。observatory.css已有120ms颜色反馈；round-two.css另有120/180ms变量。当前不是完全没有动效，不应再次堆叠标签滑动。

源码已具备data-appearance=observatory限定、经典界面持久化回退和useReducedMotion。现有规则分散在多个样式层，实施前先建立作用范围清单，不全局改动继承自上游但未使用的组件。

## 首批建议

1. 添加独立动效偏好：跟随系统/关闭；保存失败时保持当前偏好，减少动态效果优先。与深浅主题及经典界面分开，关闭动效不要求换肤。
2. 保留已有Lucian标签结构、原始曲线和时长，只把关闭动效偏好接入。面板内容即时切换，草稿/附件/滚动状态保留。
3. 为项目自有菜单和只读阅读面板加入一次性短淡入，按120–180ms评估；关闭立即生效，不等退场动画，禁止遮挡旧菜单或保留隐藏焦点。宽度与正文流动不做补间。
4. 按钮只做颜色/边框反馈，不移动发送按钮、不改变命中区域、不增加提交延迟。错误与审批即时显示。
5. 工具记录继续原生details多项展开。Lucian CLI搜索到#044 FAQ accordion，但摘要为单项展开，与工具多项对照不一致，暂不套用，也未获取/移植其源码。若后续确需更改折叠效果，再明确组件适配依据。

## 本批不包含

人物呼吸/眨眼、连续粒子、打字机回复、平滑历史自动滚动、代码逐行入场、审批延时、窗口转场；不生成新美术、不引入动画库、不改聊天/执行数据结构。

## 回退与实施边界

开始前对实际修改文件保存带SHA256的快照。新增动效样式独立文件并限定新版外观；提供应用内关闭动效，保留经典外观。检查动画取消和组件卸载，不以计时器推迟业务动作。

## 有限验收

- 独立配置下检查深浅主题、窄窗和正常宽度，键盘切换/焦点回到触发按钮。
- 系统减少动态效果和应用内关闭均应消除移动/淡入；运行时改偏好立即生效。
- 切换模式不丢草稿、切换任务不闪旧文件、快速开关菜单不留下遮罩。
- 阅读面板可选择/复制代码，流式输出不反复触发进场。
- 只对偏好持久化/失败/模式状态写针对性检查；视觉以真实打包应用核验。不重复付费API或全仓库测试。
