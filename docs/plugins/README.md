# 提示词与快捷操作插件

使用 schemaVersion 1，与[执行插件](../PLUGIN_SDK_V2.md)的格式独立。插件是 UTF-8 JSON 文件，可把常用要求整理成带参数的草稿。

## 安装与使用

1. 打开「设置 → 插件」，选择「从文件安装 / 更新」。
2. 选中 `.herta-plugin.json` 文件，查看名称、动作范围和展开后的提示词，再确认安装。
3. 返回工作台或聊天，在输入框的「快捷操作」中选择动作、填写参数。
4. 预览内容后插入草稿，检查后自行发送。默认追加；勾选替换才会覆盖当前草稿。

工作台动作只在工作台显示；聊天动作只在聊天显示。没有可用动作时先检查插件是否启用、范围是否正确。相同 ID 再次导入是更新，保留启停状态；移除不会删除原始文件或已填入的文本。

设置页「复制插件示例」可获取最小示例，仓库中也有 [example.herta-plugin.json](example.herta-plugin.json)。

## 请黑塔制作一个插件

把下列要求与自己的任务说明一起发给黑塔，并附上示例文件：

> 请参照附件制作 The Herta 提示词插件，输出一个 UTF-8 的 .herta-plugin.json 文件。保留 schemaVersion: 1，使用新的 id；为需要填写的内容定义 inputs，在 prompt 中用 {{参数id}} 引用。只使用示例支持的字段，不添加脚本、命令、权限或系统提示词字段。插件用于：在这里填写具体用途。

生成后先通过安装预览检查提示词。插件可以要求模型完成工作，但真正发送后的权限仍由当前模式和权限档位决定。插件不会自行执行代码、读取项目、发起网络请求或改变角色记忆。

## 格式约定

- 顶层必需：`schemaVersion`（1）、`id`、`name`、`version`、`description`（可为空字符串）、`actions`。
- `id`：3–80 个字符，以小写英文字母开头，其余只允许小写字母、数字、点、短横线。动作 ID 和参数 ID 也遵守此规则，各自列表内唯一。
- `version`：三段数字，如 `1.0.0`。
- 动作必需：`id`、`title`、`scope`、`prompt`、`inputs`。`scope` 为 `chat`、`workbench` 或 `both`；没有参数也要提供 `inputs: []`。
- 参数必需：`id`、`label`、`type`、`required`（布尔值）。`type` 为 `text` 或 `select`，可提供 `default`。
- `select` 额外提供 `options` 字符串数组；选项不能重复，默认值必须属于选项。`text` 不提供 `options`。
- 模板只支持 `{{参数id}}`；参数必须已定义，替换不递归执行，也不支持表达式。
- 最多 20 个动作，每个动作最多 8 个参数，选择参数最多 20 个选项。文件不超过 256 KiB；单条提示词不超过 16,000 字符，参数值不超过 4,000 字符。
- 未知字段会被拒绝。需要增加功能时应更新应用支持的格式，不能用字段名称假装能力已存在。

## 常见问题

导入报格式错误：提示会写明位置，例如「第2个动作（review） · 第1个参数（request） · label：不能为空。」，或「JSON 格式错误（第 3 行第 5 列附近）」。按位置修改即可，也可以把这条提示原样发给黑塔，请它修正插件文件。常见原因有：JSON 里的注释或尾随逗号、未知字段、ID 少于三个字符、`{{ 参数 }}` 中带空格，或模板引用了 inputs 中没有定义的参数。错误提示不会回显文件里的具体内容。

输入中途切换了聊天：旧操作的晚返回结果不会写入新聊天；回到目标聊天重新选择即可。

存储损坏：管理页提供两个入口。「恢复上次有效备份」只恢复上一份有效的插件记录。如果没有可用备份（例如只安装过一次），可以选择「另存损坏记录并重新开始」：确认后，损坏的记录会另存为 `plugins-v1.json.damaged-时间戳` 保留，插件列表清空，需要重新安装插件。两种方式都不影响历史对话和草稿。
