# 素材使用说明

The Herta是非官方同人项目，与HoYoverse没有隶属或认可关系。源码MIT授权与角色、美术、对白、声音的权利范围分开，详见[LICENSE](../LICENSE)。

当前分发素材的文件、字节、哈希及许可见[素材清单](../assets/ASSET_MANIFEST.md)。该清单仅包含实际分发的几何图标、欢迎页PNG、字体与字体元数据，不混入未采用的上游资源或本机参考图路径。

- 几何应用图标和状态图形为项目原创，使用随附的[独立MIT许可](../packages/gui/resources/licenses/atelier-geometric-LICENSE.txt)。
- 欢迎页PNG由image_gen参考作者自行绘制的原画生成，经作者确认并获准随本项目发布。参考原画不随源码或安装包分发；衍生图不套用代码MIT，也不改变角色知识产权归属。
- Maple Mono和Noto Serif SC字体分别按SIL OFL 1.1分发，完整原版权与许可随包保留；系统字体只是运行时回退，不复制进仓库。
- 欢迎人物只用于空任务欢迎页，不放在聊天、代码或审批内容后。没有持续人物动画、语音模型或3D素材的分发承诺。

构建的素材门禁核对实际文件和许可证；Electron/Chromium及软件依赖的许可由各自打包清单维护。请勿只凭本页或代码许可推断未列素材可以使用。新增或替换素材时同步更新清单、来源与适用许可，不删除原版权声明。
