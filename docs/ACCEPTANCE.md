## 记录规则

每个用例记录：用例编号、构建 commit/版本、运行环境、步骤、预期结果、实际结果、证据位置、状态和缺陷编号。状态只用“通过 / 失败 / 阻塞 / 未执行 / 不适用（附原因）”。截图可以证明布局，不能单独证明审批无副作用、密钥安全或持久化正确。

真实 API 测试与 mock 测试必须分列：mock 验证状态机及可重复异常，真实 API 验证服务协议和实际工具流程；一者不能替代另一者。凭据由用户在本机配置，报告不得包含完整密钥。缺少账号或额度时标记阻塞，保留已经完成的独立验证。

| A03 | 触发需审批操作，先拒绝，再在新操作中批准 | 拒绝不产生副作用；批准仅授权展示的具体操作；拒绝状态不会显示成功 | 前后文件/进程检查；批准内容与执行参数对照 |
| A04 | 在等待审批时取消；之后尝试旧审批操作 | 旧审批失效，不能继续执行，界面清楚说明已取消 | 无副作用证据及状态记录 |
| A05 | 分别在模型流输出和工具运行时取消 | 输出停止或明确说明服务侧限制；本地工具与子进程按定义停止；不把取消算成功 | 请求/进程生命周期与最终状态 |
| A06 | 输出中断网或模拟断流，恢复网络后按界面操作继续 | 保留已收到内容，明确错误；重试不静默重复有副作用的操作 | 确定性 mock + 至少一种真实断流尝试，分别记录 |
| A07 | 配置无效凭据、触发超时或服务不可用 | 显示可理解的失败原因和恢复入口，不泄漏密钥，不无限转圈 | mock 异常集；真实无效凭据检查 |
| A08 | 两个会话切换，至少一个仍在输出 | 内容、审批和工具事件始终归属正确会话，不串线 | 会话 ID 关联的脱敏记录 |
| P01 | 完成对话、退出并重启 | 会话列表、消息和必要工具记录恢复；模型配置按定义保留 | 重启前后核对 |
| P02 | 在输出/工具/审批未完成时退出或中断，再重启 | 显示中断状态，不伪称完成，不自动重跑有副作用工具；恢复操作明确 | 重启前后状态与磁盘/进程检查 |
| S01 | 设置、使用、更新、删除 API 密钥；检查日志与数据文件 | 不明文写入普通配置/日志，不发送给无关来源，不暴露给 renderer；删除后无法继续读取旧值 | 不含秘密值的存储机制审查和检查结果 |
| S02 | 尝试从 renderer 传入非法 IPC 参数或越界路径 | 主进程独立校验并拒绝；错误不会扩大授权范围 | 自动化或手动边界用例 |
| S03 | 展示带脚本/危险链接的模型 Markdown、打开外链 | 模型内容不能执行任意脚本或获取系统权限；外链有明确处理策略 | 渲染与主进程代码审查及验证 |
| R01 | 新用户数据目录/干净 Windows 环境安装并启动；再升级或重新安装 | 依赖资源完整，用户数据位置合理，既有会话和配置按策略保留 | 环境说明、安装日志、升级前后核对 |
| R02 | 检查构建包与许可证 | 无开发密钥、个人日志、无关工作区文件；许可证和素材来源随项目可追溯 | 包内容检查、来源清单 |
| R03 | 检查 appId、用户数据路径和更新行为 | 项目使用独立标识与数据目录，不污染上游安装数据，不连接上游更新通道 | 配置审查、运行路径与请求记录 |
| R04 | 无语音模式构建并启动 | 不依赖缺失 voice/TTS 资源；不可用入口明确隐藏或禁用；第三方 notices 校验仍有效 | 构建输出、配置与桌面入口检查 |

## 缺陷优先级与停止条件

- **阻断**：启动不了、主要流程无法完成、用户数据损坏、密钥泄漏、未批准工具执行。发现后优先修复，不进入发布。
- **高**：取消/审批错误、会话串线、重启重复执行、常见 Windows 环境不可用、主操作被布局遮挡。核心交付前必须解决。
- **中**：特定次要流程故障、可恢复但明显妨碍使用的问题。给出复现和计划，由用户决定是否纳入下一轮。
- **低**：局部间距、装饰和非阻断文案。集中处理，不据此无限延长项目。

建议按四轮完成，而不是预先承诺固定轮数。满足以下全部条件即可停止主迭代：用户确认视觉方向；真实 Windows exe 可用；三个协议模式分别完成真实服务的对话—审批—工具—变更流程，自定义 Base URL 和 Provider 管理通过；取消、断流、会话恢复和密钥保护通过；无阻断或高优先级缺陷；剩余问题清楚且用户接受。若需要额外一轮，每轮只处理有验收条件的具体缺口，完成后重新判断是否停止，避免无目标地增加功能。
