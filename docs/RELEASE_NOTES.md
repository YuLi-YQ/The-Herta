# 0.8.10 功能说明

本页概述当前公开源码，不代表每个历史0.8.10安装包都包含这些功能。具体交付批次、文件和下载状态以[GitHub Releases](https://github.com/YuLi-YQ/The-Herta/releases)为准。

- 工作台与独立聊天共用新版视觉系统，保留深紫/白灰主题、关闭动效和系统减少动态效果。
- 多服务商连接、文本/工具验证、独立手动识图检测，以及输入区模型/思考强度/支持的搜索选择。
- 附件预览、移除、失败重试、待发恢复；历史图片可停止或恢复发给模型，预览仍保留。
- 工作台提供真实工具过程、文件差分、结果与用时；执行器的纯文字答复也会交回黑塔，明确区分模型文字与工具验证事实。
- 聊天拥有自己的历史、附件、文件生成与可管理记忆，不隐式读取项目或运行工作区操作。
- 目标、只读计划、上下文整理、Markdown导出与本地反馈草稿；不会自动发送反馈。
- 提示词插件和本地JavaScript执行插件并存。执行插件声明十二类能力，支持受控结果视图、独立文本产物、可审阅修改提案和逐条确认的本机命令。
- 插件工坊提供已验证模型生成、独立候选、源码编辑、内存样本试跑、实际差异/权限审阅和明确确认安装，不自动运行。
- 插件资料共享逻辑空间预算；安装/私有资料有明确恢复，制作草稿与可清理安装资料经过预览确认删除。产物和提案不会作为缓存自动清理。
- 插件联网可显式使用HTTP(S) CONNECT代理及可信DoH，保持公网目标与TLS验证，不修改系统设置。

已完成单个DeepSeek Flash服务的有限真实视觉、摘要和插件生成检查，以及一组显式代理/DoH公网正向检查。它们不能保证所有服务商、模型、代理或原生操作组合都兼容；系统文件入口、输入法、窗口缩放和具体业务仍需结合环境使用反馈。

升级或迁移前备份完整资料目录；旧版可能不认识新增状态。TTS、远程插件市场和无人确认修改应用核心未启用。使用方法见[README](../README.md)，权限与开发契约见[插件SDK](PLUGIN_SDK_V2.md)。
