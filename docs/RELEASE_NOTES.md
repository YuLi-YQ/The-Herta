# The Herta 0.8.10 · 聊天状态修复

发布批次：v0.8.10-r27.1。应用版本保持0.8.10，旧发布保留。

- 读取附件时切换聊天，新聊天不再被旧请求阻塞。旧附件晚返回时，不会显示到新聊天或提前解锁新聊天正在读取的附件。
- 切换后停止读取旧批次尚未开始的文件；已经执行的解析自然结束。
- 存储扫描错误只在存储面板显示，不清除聊天已有的错误提示。扫描中重新打开面板不会重复发起刷新。

验证：17项聊天界面检查、GUI类型检查、Windows打包和安装载荷检查通过。本批未重复完整桌面交互、全部DPI或付费API验收。

## 保留此前的后台扫描优化

- 存储容量和图片引用检查改为后台扫描，刷新期间仍可使用聊天控件。
- 重复刷新共享一次扫描，超时或关闭应用时退出扫描；保留读取预算与不完整结果提示。
- 本批只优化存储检查；历史首次载入和普通保存沿用原有方式，没有增加图片删除功能。

验证：51项针对性检查、GUI类型检查、Windows打包通过；实际打包应用的合成样本中，后台扫描期间聊天状态查询约1–2毫秒返回。这是单机有限实测，不是性能保证；未重复全部DPI组合或付费API测试。

## 保留此前的聊天图片与存储功能

- 聊天页新增“存储空间”，查看记录与图片库已用/剩余容量及独立图片数；接近上限时提示。只在打开或刷新时统计。
- 历史图片改为展开附件后读取，收起后移除预览。聊天状态不再反复携带图片编码；发送前只加载所选续聊范围，缺失或损坏的图片仍会明确阻止请求。
- 新增只读引用检查，区分聊天记录使用、仅相邻自动备份使用和未找到引用的图片。损坏、未知或超出读取预算的记录会标记不完整。
- 引用检查不包含移到其他位置的备份，也不校验图片内容完整性；“未找到引用”不表示可以安全删除。本版没有图片清理或自动删除。
- 存储格式保持schema3；旧内嵌图片记录仍在首次保存时备份并迁移。保留R22深浅主题和可回退界面：设置 → 外观 → 界面风格 → 经典界面 · 原版。

验证：图片按需读取批50项相关检查、引用检查批34项相关检查通过（有重叠，不累加）；GUI类型检查、Windows打包及独立桌面预览/存储面板验证通过。未增加付费API请求，尚未进行大型图片库性能和全部DPI组合验收。

## 包含此前的图片存储与聊天功能

本次补充独立图片存储：相同图片只存一份，不再随每次聊天保存重写图片编码。旧v2聊天记录首次保存前生成备份；图片缺失或损坏时保留文字历史，并阻止缺图上下文被静默发送。

图片位于聊天JSON旁的 `.images` 目录；备份/迁移请复制完整用户数据目录。旧版不能读取新版schema 3记录；如需回退，请使用升级前备份。图片库支持按需加载，暂不自动清理；文字记录上限64 MiB、图片库上限256 MiB。

本批51项相关检查最终通过（迁移测试已更新至schema 3），GUI类型检查、打包与隔离桌面迁移验证通过。没有新增付费API调用。

同时包含R21第三至七批已完成的功能：

- 原生联网搜索：已适配的DeepSeek/Anthropic Messages与OpenAI Responses，默认关闭；带来源引用和可展开搜索记录。
- 搜索暂停可有限续接，前台执行尝试共用最多3次搜索预算；显示明确失败原因，避免无限续接。
- 聊天上传UTF-8文本、代码、PDF/DOCX文字附件；发送前预览，生成的文本或代码可保存为文件。
- 聊天PNG/JPEG图片附件、历史预览与三协议多模态编码。图片要求已验证模型及已适配官方视觉模型，不支持时保留草稿并提示。
- 保留此前的聊天记忆、消息时间、多服务商配置、工具记录与差分、权限档位、深浅主题。

验证：各批执行针对性测试及Windows桌面检查；最新图片批51项相关测试、类型检查、打包与实际桌面预览通过。DeepSeek原生搜索已真实调用验证；本批没有真实OpenAI/Anthropic视觉调用验收。

限制：PDF/DOCX仅提取文字，不含扫描OCR和版式；图片单张2 MiB、边长4096像素以内，需附带文字问题。模型适配列表保守；其他Office附件、可选插件和完整角色动效尚未完成。文字记录及图片库的容量分别见上文。

安装包未提供受信任的发行者签名。更新前建议保留聊天数据备份。安装版和便携版均在本页提供SHA256校验文件。
