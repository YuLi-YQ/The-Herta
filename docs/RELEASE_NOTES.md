# 0.8.10

The Herta 是基于 PersonaCLI/Herta 的个人 Windows 桌面衍生项目。

本版包含多服务商配置、保存并验证、工作台项目/任务管理、权限档位、真实文件差分、工具过程、独立聊天、深浅主题。

本次补充：
- 移除工作台恢复入口，不删除项目磁盘文件。
- 消息显示本地具体时间；缺失旧时间不伪造。
- 聊天独立记忆管理、空闲整理、用户确认的保存/更正/忘记操作。
- 上传 UTF-8 文本/代码附件，生成的文本或代码可保存为文件；不访问项目和执行命令。

验证：68项相关自动测试、GUI类型检查、Windows个人打包通过；隔离桌面及一次真实DeepSeek附件/记忆建议请求通过。其他供应商本次未新增真实调用验收。

尚未交付：原生联网搜索、PDF/图片/Office聊天附件、插件系统和完整角色动效。

记忆整理会使用用户全局绑定的黑塔模型并产生API用量，可在聊天右上角关闭。只保存可对应用户原话的片段；用户删除或更正后，不重新整理此前历史。记忆不等于上下文压缩。
