# The Herta

以大黑塔的角色风格展开协作的 Windows 桌面 AI 助手。

在工作台里处理项目、执行工具、检查文件改动；也可以切换到独立聊天，讨论问题、发送附件、整理记忆。模型、权限、过程和结果都尽量保持清楚，让日常使用少一些来回切换。

**0.8.10 · Windows x64 · Electron + React + TypeScript**

[下载安装包](https://github.com/YuLi-YQ/The-Herta/releases) · [首次使用](#首次使用) · [插件](#插件) · [从源码运行](#从源码运行) · [反馈问题](https://github.com/YuLi-YQ/The-Herta/issues)

本文介绍当前源码的功能。下载时请同时查看对应 Release 的说明；相同应用版本号下，不同交付批次可能包含不同改动。

## 可以做什么

| 区域 | 功能 |
| --- | --- |
| **编程工作台** | 管理项目与任务，选择模型和权限，执行工具，查看文件差分、过程记录、任务结果及用时 |
| **与黑塔聊天** | 独立的聊天历史、草稿、附件、文件生成和记忆；不会隐式读取项目或运行工作区命令 |
| **文件与图片** | 待发文件卡、图片预览与移除；读取受支持的文本、代码、PDF、DOCX和图片；控制历史图片是否继续发送给模型 |
| **目标与上下文** | 设置目标、进入只读计划模式、整理上下文、导出对话或生成本地反馈文件 |
| **插件工坊** | 让黑塔生成插件候选，检查源码与差异、使用样本试跑，再明确授权安装 |
| **桌面体验** | 工作台与聊天统一布局，深紫与白灰主题，可关闭的轻量动效，以及系统减少动态效果支持 |

工作台中的黑塔负责交流与安排，执行模型负责具体操作，两者可以使用不同模型。工具执行成功、模型给出结论和任务已经验证会分别记录。

## 安装

打开 [Releases](https://github.com/YuLi-YQ/The-Herta/releases)，选择交付批次并下载 Windows x64 文件：

| 文件 | 用途 |
| --- | --- |
| `The-Herta-Setup-0.8.10-x64.exe` | 常规安装，可选择安装目录 |
| `The-Herta-0.8.10-portable-x64.exe` | 直接启动应用，无需常规安装 |

**便携启动不代表资料随 exe 移动。** 默认资料目录仍为 `%APPDATA%\HertaAtelier`。升级或迁移前请备份完整目录，包括附件和图片子目录；项目源文件及另存的输出文件需要另外保留。

应用需要自行配置 API Key，服务用量由相应服务商计算。安装包不包含可供共同使用的密钥。

## 首次使用

1. 打开 **设置 → 连接与模型**，选择服务商，填写 API Key，并选择模型。
2. 点击 **保存并验证**，按聊天或编程用途完成文本、工具验证；如需发送图片，再点击 **测试识图**。验证会发送小型请求。
3. 设置工作台的黑塔模型与执行模型。独立聊天可以另选模型；思考强度及受支持的联网搜索可在输入框附近调整。
4. 处理项目时，打开文件夹并新建任务；没有选择项目时可使用独立工作区。日常交流则进入“与黑塔聊天”。
5. 通过附件入口、粘贴或拖放添加受支持文件。发送前可查看文件卡、预览图片、移除误选文件。

默认 **Enter 换行，Ctrl+Enter 发送**。发送失败时保留草稿和相关状态，便于检查后继续。

内置 OpenAI、Anthropic、Google Gemini、DeepSeek、Qwen、Kimi、GLM 等连接预设，也可手动填写兼容接口。支持 OpenAI Responses、OpenAI Chat Completions 和 Anthropic Messages；Gemini 预设使用其 OpenAI 兼容接口。预设模型名只是配置入口，不保证账号拥有访问权限。

### 权限怎么选

| 权限 | 适用情况 |
| --- | --- |
| 只读 | 先了解项目、检查代码或制定方案 |
| 工作区编辑 | 在项目范围内修改，需要确认的操作会显示审批 |
| 完全访问 | 允许更广的本机操作，请先确认任务范围 |

权限档位不是系统提权，也不是操作系统沙箱。**执行插件发起的每条本机命令都会单独确认，包括完全访问模式。** 获准运行的程序仍以当前用户身份访问本机资源。

## 快捷操作与指令

在输入框输入 `/`，或打开快捷操作菜单，查看当前区域可用的操作。

| 指令 | 用途 |
| --- | --- |
| `/goal` | 在工作台或聊天中设置、修改和结束目标，保留结果记录 |
| `/plan` | 工作台进入只读计划模式；计划可编辑，退出后可放入草稿，不自动执行 |
| `/compact` | 工作台安排整理旧记录；聊天由模型起草续聊要点，检查并应用后生效 |
| `/export` | 导出当前任务或聊天为本地 Markdown，附件列出名称和类型 |
| `/feedback` | 预览问题描述和自行选择的诊断信息，保存为本地文件 |

整理上下文会保留原始记录，失败不会被标记为完成。模型生成的要点也可以回到原文核对。

## 聊天记忆

可以查看、保存、更正和删除记忆，也可以关闭记忆功能。启用空闲整理后，应用会在空闲时使用绑定模型整理聊天中的信息，前台回复优先。

记忆属于独立聊天，不会让聊天自动获得项目权限。记忆整理会调用所选模型，相关内容会发送给对应服务商。

## 插件

**提示词与快捷操作插件**从本地 JSON 安装，填写参数后生成可编辑草稿，由你决定是否发送。

**执行插件**使用受限 JavaScript 运行环境，通过声明的能力访问宿主功能。安装前可以检查源码、改动和权限，安装后可以启停、调整权限或回退版本。能力包括项目文本读取、文件修改提案、生成文件、私有资料、草稿建议、结果视图、受限 HTTPS和逐条确认的本机命令。

想让黑塔制作插件，进入 **设置 → 插件 → 执行插件 → 让黑塔制作**：

1. 选择已验证的制作模型，描述希望实现的操作。
2. 生成独立候选，检查或修改源码。
3. 使用样本试跑，查看结果与过程。
4. 审阅源码差异和请求的能力，明确确认安装。

生成不会自动安装，安装也不会自动运行。试跑使用内存样本，不代表真实网络、项目或命令已经执行成功。插件资料、生成文件、修改提案和制作草稿共同受本地存储预算管理；安装资料与私有资料提供恢复或重建入口，制作草稿和可清理的安装资料须明确确认后删除。

## 联网与数据

模型的“联网搜索”和插件的“联网请求”是两项独立能力。关闭搜索不会把模型调用变成离线，也不会撤回已授予插件的网络权限。

插件可单独配置 HTTP(S) CONNECT 代理和可信 HTTPS 解析服务，不修改系统网络。代理需要明确的数字 IP 地址；目标仍需通过公网地址与 TLS 检查，目前不支持 SOCKS、PAC或带账号密码的代理地址。详见[插件联网说明](docs/PLUGIN_NETWORK_V1.md)。

会话、配置、附件副本和记忆保存在本机。使用模型、识图、搜索、记忆整理或插件联网时，相应内容会发送到选定服务。请只授予任务需要的能力，不要将 API Key、私人对话或完整资料目录上传到 Issue、插件包或公共仓库。

## 当前边界

- 图片、工具、搜索、思考强度和用量字段取决于服务与模型；不支持或缺少的数据会显示占位。
- 已完成一个 DeepSeek Flash 服务的真实识图、插件生成与摘要验证，不能据此保证所有服务商、协议和模型都兼容。
- 文件读取支持取消，但部分同步解码步骤不能立即中止；图片 token 尚未纳入工作台上下文用量估算。
- 当前发行目标为 Windows x64；TTS、远程插件市场和自动修改应用核心未启用。
- 项目持续迭代中。升级前备份资料；降级版本可能不认识新增状态字段。

## 从源码运行

在完整源码根目录打开 Windows PowerShell：

```powershell
.\scripts\bootstrap-windows.ps1
```

脚本准备固定的 Node 22.23.3、pnpm 9.15.0 和桌面依赖。随后按需要分别运行：

```powershell
# 构建共享包
.\scripts\pnpm.ps1 build

# 启动开发桌面
.\scripts\pnpm.ps1 dev:gui

# 生成 Windows 安装包与便携包
.\scripts\pnpm.ps1 dist:personal
```

`pnpm.ps1` 会结束当前脚本调用，自动化时请分别调用各条命令。打包产物位于 `packages/gui/release-round-21/`；目录名沿用构建配置，交付内容以发布说明为准。

修改后按影响范围运行定向测试与类型检查。测试请使用独立资料目录和临时项目，不要用日常聊天或个人文件作为样本。
