# The Herta · Windows 桌面编程助手

当前个人交付版 **0.8.10**（2026-10-13）。以大黑塔为协作主体，在独立 Electron 桌面内管理项目与任务，调用用户配置的模型服务执行本地编程、补充信息、控制权限并审阅结果。

支持简约深紫与白/灰白浅色主题、跟随系统，保留少量几何星象元素，不以角色插画占用代码阅读区域。欢迎页已加入用户确认、依据用户参考图生成的大黑塔插画；素材与字体来源见 [素材审计](docs/ASSET_AUDIT.md)。个人构建关闭语音、TTS、3D及上游自动更新。

## 使用成品

Windows x64 安装包：`packages/gui/release-round-21/The-Herta-Setup-0.8.10-x64.exe`；便携版：同目录 `The-Herta-0.8.10-portable-x64.exe`。不需要源码或开发服务器。[GitHub Release](https://github.com/YuLi-YQ/The-Herta/releases)提供安装版、便携版及校验文件；搜索与附件更新使用发布批次标签 `v0.8.10-r21.7`，应用版本仍为0.8.10。

数据默认位于 `%APPDATA%/HertaAtelier`，便携版也使用该位置，不承诺数据随exe移动。升级前建议备份完整数据目录。当前为个人未签名发行，未提供自动更新。

1. 在「设置 · 连接与模型」选择常用服务商预设，填写 Key 并选择模型；也可自定义 Provider，选择实际支持的协议：OpenAI Responses、OpenAI Chat Completions 或 Anthropic Messages。填写服务根 Base URL、Key 和模型，支持发现或手填模型。OpenAI兼容不代表支持Responses，按供应商实际接口选择。
2. 点击「保存并验证」，选择仅聊天或编程用途，再绑定角色与执行器；两者可独立选择。仅「保存连接」不请求API；「保存并验证」会进行小型测试。密钥由本机安全存储保护，不能从配置页重新读出原值。
3. 打开项目并新建任务。Enter换行、Ctrl+Enter发送；输入区可切已配置模型和受支持的思考强度。活动轮采用开始时的配置。
4. 按需选择只读、工作区编辑或完全访问。完全访问不等于系统提权，权限策略不是操作系统沙箱。出现补充信息卡时选择或填写答案，显式提交后继续；未提交草稿可跨重启恢复。
5. 查看每轮状态、用时、任务结果和可折叠工具过程；文件悬停预览，点击打开侧栏只读历史差分及全文。新增/删除行有颜色与符号，搜索结果可定位已记录的行。
6. 项目与任务可右键管理、置顶、重命名和移除。移除项目不删除磁盘源码；工作台不再提供恢复入口。中断记录不会自动重放工具。

7. 标题栏「与黑塔聊天」选项卡进入独立闲聊，只需验证文本模型；历史保存在本机，不读取项目或执行命令。支持附加 UTF-8 文本/代码、PDF及DOCX提取文字，生成的代码块可保存为文件，无需工作台审批。切换「工作台」后再发起编程任务，两边草稿和页面状态保留。聊天输入区可调整受支持的思考强度和回复额度，具体失败原因显示在消息中。可新建、切换、重命名、置顶、回收和恢复聊天，草稿按聊天保存。“续聊范围”可保留最近几轮并填写要点，原文保留；没有自动摘要。首次升级旧聊天会先备份。

8. 聊天右上角「黑塔的记忆」可查看、保存、更正或忘记事实，也可关闭记忆。聊天中的记忆建议经确认后保存。空闲5分钟后使用默认黑塔模型整理新增对话，最多每30分钟一次；只保留用户原话片段，不从附件抽取记忆。前台回复优先。消息显示本地日期和具体时间，旧记录缺失时间时不伪造。

## 数据与能力边界

- 已有实际三协议兼容服务、文件/命令、审批和恢复证据；用户另报告真实OpenAI/Anthropic与干净Windows10通过。不是所有服务和模型的兼容保证。
- 用量与缓存仅显示可信服务数据；未接入或缺失字段显示 `--`，上下文窗口和生成速度不凭空估算。
- 任务结果来自真实工具记录；退出码0不等于整个需求已验证。文件卡对无法确定作者的变化明确保留归属限制。
- 历史快照有范围和容量上限，二进制、非UTF-8、超限或未扫描内容会提示限制；不会用今天的磁盘内容伪造旧轮快照。极端项目性能测试按用户要求暂缓。
- 思考强度按已支持型号开放；思考过程只展示服务公开返回的文本或摘要，不展示私有续接数据。没有新增图片理解、语音、同步或回滚功能。

## 运行与构建

在Windows PowerShell执行 `./scripts/bootstrap-windows.ps1`，准备固定Node22.23.3与pnpm9.15.0，再执行：

- `./scripts/pnpm.ps1 dev:gui`：开发桌面窗口。
- `./scripts/pnpm.ps1 dist:personal`：构建Windows安装包与便携版，目前输出 `packages/gui/release-round-21/`。
- `./scripts/pnpm.ps1 check`：完整编译、类型、格式及测试检查。日常修改选择相关定向测试即可。

不提交运行时、依赖、构建产物或凭据。保留PersonaCLI上游MIT许可与必要归属；角色素材不自动获得MIT授权。用户自行提交上传。
